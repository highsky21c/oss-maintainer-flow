# Maintainers

Primary maintainer: 김준형 (`highsky21c`)

## Responsibilities

- Review incoming issues and pull requests
- Keep triage rules explainable and documented
- Maintain CI and tests for every supported workflow
- Cut releases from reviewed changelog entries
- Route security-sensitive reports through the security policy

## Review expectations

- Issues should receive a label or maintainer note before implementation starts.
- Pull requests should include tests or a clear reason tests are not needed.
- Changes affecting triage decisions should include examples.
- Release-related changes should update `CHANGELOG.md` or release documentation.

## Decision process

This project is currently maintained by one primary maintainer. Technical decisions are made in public issues when they affect user-visible behavior, privacy, or maintainer workflow assumptions.

## Adding maintainers

Future maintainers should have a record of constructive issues, pull requests, or review comments. Maintainer access should be granted only after the contributor has demonstrated care with privacy-sensitive and security-sensitive workflows.
