# Changelog

All notable changes to this project are documented here.

## Unreleased

### Added

- GitHub issue and pull request import command for producing offline JSON exports.
- `--output` support for writing JSON exports and Markdown reports to files.
- Optional JSON config for project-specific triage rules and security terms.
- Release checklist command for validating PR metadata and changelog coverage.

## 0.1.0 - 2026-06-24

### Added

- Issue triage command with label suggestions and explainable rationale.
- Security-sensitive issue detection for terms such as credential leaks and injection reports.
- Release-note drafting command for merged pull request metadata.
- Maintainer health report command for triage and release metadata coverage.
- README, roadmap, contribution guide, security policy, maintainer guide, tests, and CI.
