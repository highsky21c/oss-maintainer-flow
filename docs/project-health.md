# Project Health Signals

This file tracks the signals the project is trying to make visible for maintainers and reviewers.

## Current strengths

- Public repository with source code, examples, tests, CI, and MIT license.
- Maintainer-facing commands for issue triage, release notes, and health reporting.
- Security policy and conservative security-sensitive issue detection.
- Contribution guide, PR template, issue templates, roadmap, and changelog.

## Current limitations

- The project is new and does not yet have external usage metrics.
- There are not yet external contributors or reviewed pull requests.
- GitHub API import is planned but not implemented in the first release.

## Near-term improvements

- Publish roadmap issues for GitHub import, configurable rules, AI-assisted summaries, and release checklists.
- Tag `v0.1.0` after the baseline workflow is pushed.
- Add fixture data for more ecosystems and maintainer workflows.
- Keep all project status claims grounded in repository-visible evidence.
