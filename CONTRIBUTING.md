# Contributing

Thanks for helping improve OSS Maintainer Flow.

## Development setup

```bash
python -m pip install -e .
python -m pip install pytest
python -m pytest
```

## Contribution guidelines

- Keep maintainer-facing output clear and reviewable.
- Add or update tests for triage rules and release-note rendering.
- Avoid sending project data to third-party services without an explicit user action.
- Prefer small pull requests with a focused explanation.

## Maintainer workflow

1. Triage new issues weekly.
2. Mark security-sensitive reports for private review.
3. Keep release notes generated by the tool human-reviewed.
4. Use issues for roadmap discussion before large changes.
